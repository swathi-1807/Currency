

💱 Currency Converter (Java Console App)

A simple Java program to convert currencies between INR, USD, and EUR using fixed exchange rates.

 💡 Features

* Convert between:

  * INR ↔ USD
  * INR ↔ EUR
  * USD → INR
  * EUR → INR
* Console-based input/output

 🛠 How to Run

```bash
javac Currency.java
java Currency
```

🧾 Example

```
Source Currency: USD  
Target Currency: IND  
Amount: 10  
Converted Amount is 835.0 IND
```

⚠️ Note

* Only supports INR, USD, and EUR
* Uses static conversion rates
